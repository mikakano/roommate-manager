# 合租生活管家

把账算清，把家照顾好。一个面向年轻人合租场景的交互网页雏形，集中管理共同费用、清洁值日、公共物品和室友公约。

**作品入口：[在线体验](https://mikakano.github.io/roommate-manager/)**

## 功能

| 模块 | 能做什么 |
| --- | --- |
| 生活总览 | 查看当前室友待结清金额、当月公共费用、今日值日和待补货物品 |
| 费用 AA | 新增费用、选择付款人与参与者、自动均摊、标记或撤销结清、删除账单 |
| 清洁值日 | 查看本周或全部任务、新增值日、更换本周任务负责人、完成或撤销任务 |
| 公共物品 | 登记库存和提醒阈值、记录消耗或补货、自动显示低库存提醒 |
| 室友公约 | 新增、编辑、删除共同生活约定 |

预置“阳光合租屋”和4位室友，首次打开即有演示内容。顶部可切换室友查看视角，支持手机和电脑。

## 快速体验

1. 在首页记一笔100元的公共费用，选3位参与者，查看33.34、33.33、33.33元的分摊预览。
2. 进入费用页标记某位室友已结清，查看首页待偿还金额变化。
3. 完成今天的值日，查看首页待办变化。
4. 记录垃圾袋消耗，库存达到阈值后出现补货提醒；补货后提醒清除。
5. 编辑一条室友公约，再刷新页面确认数据保留。
6. 如需重新体验，可点击“恢复演示数据”，确认后覆盖本地修改。

## 演示范围

- 数据仅保存于当前浏览器，不会同步到其他设备或室友。
- 切换室友仅改变查看视角，没有真实账号或权限隔离。
- 结清仅是记录状态，不触发真实支付。
- 提醒仅在网页内显示，不发送短信、邮件或推送。
- 公约是演示内容，不表示真实室友已同意。

## 单文件运行

`index.html` 内置全部样式、逻辑和示例数据，无外部依赖、无需安装或构建。下载后可直接用浏览器打开，也可以在静态网站服务中发布。

此仓库用于发布演示版。后续更新同一仓库的 `main` 分支中的 `index.html`，即可通过 GitHub Pages 在原地址迭代。
