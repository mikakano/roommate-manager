# 合租生活管家

把账算清，把家照顾好。一个面向年轻人合租场景的交互网页雏形，集中管理共同费用、清洁值日、公共物品和室友公约。

**作品入口：[点击体验](https://mikakano.github.io/roommate-manager/)**


## 功能

- **生活总览**：当前室友待结清金额、本月公共费用、今日值日、低库存提醒和最近账单。
- **费用 AA**：新增账单，选择付款人及参与室友，实时预览等额分摊，标记或撤销结清，删除错误账单。
- **清洁值日**：本周排班和全部任务查看，新增值日，调整本周任务负责人，完成或撤销任务。
- **公共物品**：登记物品、库存及阈值，记录消耗或补货，随库存变化更新补货提醒。
- **室友公约**：新增、编辑、删除约定，展示最近更新时间。

预置“阳光合租屋”和4位室友，首次打开即有可体验内容；顶部可切换室友查看视角。操作后数据保存在当前浏览器，刷新后可继续体验，也可通过确认恢复演示数据。

## 实现中关注的细节

### 1. 费用分摊保持总额准确

费用按整数“分”计算，再分配除不尽的余数。例如100元由3人承担，结果为33.34、33.33、33.33元，总额仍为100元。付款人的本人份额无需偿还，首页待结清金额包含历史未结清费用，避免被月份筛选遗漏。

### 2. 操作与结果相互关联

新增费用、标记结清、完成值日和调整库存后，首页对应汇总会更新。库存达到提醒阈值时提示补货，补货后高于阈值则清除提示，让用户能看到操作带来的结果。

### 3. 处理常见错误和重复体验

金额、必填内容和数量有基础校验，消耗数量不能超过库存。结清和值日完成可以撤销，删除和恢复数据需要确认；本地存储不可用时提供提示。界面包含空状态、操作反馈和键盘焦点样式，并适配手机布局。

### 4. 用技术取舍支持限时交付

首版使用静态前端和浏览器本地存储，将开发重点放在四项需求的可操作流程。全部样式、逻辑与示例数据内置于一个 `index.html`，没有外部资源依赖，便于直接展示、上传和持续更新。


## 建议体验顺序

1. **费用**：新增一笔100元账单，选择3位参与者，观察分摊预览；保存后标记结清，再查看首页金额变化。
2. **值日**：将当前室友今天的任务标记完成，查看首页待办数量变化。
3. **物品**：消耗一卷垃圾袋，使库存达到阈值；再补货，观察提醒变化。
4. **公约**：编辑一条共同约定，刷新页面确认保留。

如需重新体验，点击“恢复演示数据”，确认后回到初始示例。


## 后续迭代方向

优先完善线上体验和编辑能力，再根据真实合租使用需求增加自定义分摊、可配置轮班、物品操作记录及多人共享。真实支付和外部通知需要在产品需求与使用边界明确后另行评估。
